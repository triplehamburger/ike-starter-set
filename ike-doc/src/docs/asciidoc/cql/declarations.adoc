== Declarations

=== Library (5)

Keywords of a library's header: its name and version, the data models it uses, and the libraries it includes.

Members: <<term-called,`called`>>, <<term-include,`include`>>, <<term-library,`library`>>, <<term-using,`using`>>, <<term-version,`version`>>

=== Terminology (6)

Keywords that declare the code systems, value sets, codes, and concepts a library uses.

Members: <<term-code,`code`>>, <<term-codesystem,`codesystem`>>, <<term-codesystems,`codesystems`>>, <<term-concept,`concept`>>, <<term-display,`display`>>, <<term-valueset,`valueset`>>

=== Parameters (2)

Keywords that declare a library parameter and its default value.

Members: <<term-default,`default`>>, <<term-parameter,`parameter`>>

=== Statements (6)

Keywords that set the context statements are evaluated in, such as Patient, and define named expressions and functions with their access level.

Members: <<term-context,`context`>>, <<term-define,`define`>>, <<term-fluent,`fluent`>>, <<term-function,`function`>>, <<term-private,`private`>>, <<term-public,`public`>>
