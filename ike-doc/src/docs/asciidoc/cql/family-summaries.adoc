== Family Summaries

The keywords are grouped into four families, following the CQL Author's Guide, with the operator categories of the CQL Reference (Appendix B) as the Operations categories. The same hierarchy files the keyword concepts in Komet, under the CQL keyword root.

[listing]
----
CQL keyword
├── Declarations (19)
│   ├── Library (5)
│   ├── Terminology (6)
│   ├── Parameters (2)
│   └── Statements (6)
├── Queries (16)
│   ├── from
│   ├── Filtering (4)
│   ├── Shaping (5)
│   └── Sorting (6)
├── Values (24)
│   ├── Simple Values (3)
│   ├── Type Names (5)
│   └── Calendar duration keywords (16)
└── Operations (63)
    ├── Logical Operators (5)
    ├── Type Operators (5)
    ├── Comparison Operators (1)
    ├── Arithmetic Operators (6)
    ├── Date and Time Operators (17)
    ├── Interval Operators (15)
    ├── List Operators (9)
    └── Conditional Expressions (5)
----

=== Declarations (19)

Keywords that declare the parts of a CQL library: its identity, data models, included libraries, terminology, parameters, context, and named statements.

=== Queries (16)

Keywords that build queries over lists of data: choosing sources, filtering, relating, shaping, and sorting results.

=== Values (24)

Keywords that name CQL's types and write values directly.

=== Operations (63)

Keywords for CQL's operators, grouped by the operator categories of the CQL Reference.
