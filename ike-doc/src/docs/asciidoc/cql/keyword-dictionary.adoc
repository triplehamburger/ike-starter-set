[#keyword-dictionary]
== Keyword Dictionary

All 122 CQL keywords, alphabetically. Definition, example, and current Komet status for each.

[[term-after]]
[discrete]
==== *after*

`Timing Operator` -- (Data & Timing Operators > Timing Operator) Not yet in Komet

Relational operator testing whether one date, time, or interval occurs later than another (e.g. ‘X after Y’).

[source,cql]
----
"DischargeDateTime" after "AdmissionDateTime"
----



* * *

[[term-aggregate]]
[discrete]
==== *aggregate*

`Query Clause` -- (Query & Control Flow > Query Clause) Not yet in Komet

Introduces the aggregate clause of a query, reducing a list to one accumulated value, similar to a ‘reduce’ function (e.g. ‘aggregate Result starting 0: ...’).

[source,cql]
----
aggregate "RunningTotal" starting 0: RunningTotal + Claim.amount
----



* * *

[[term-all]]
[discrete]
==== *all*

`Query Clause` -- (Query & Control Flow > Query Clause) Not yet in Komet

Modifier that keeps duplicate values instead of the default distinct behavior, used in a return or aggregate clause.

[source,cql]
----
["Condition"] C return all C.code
----



* * *

[[term-and]]
[discrete]
==== *and*

`Logical Operator` -- *Implemented in Komet*

Boolean conjunction — true only if both operands are true (three-valued logic: an unknown operand can yield an unknown result).

[source,cql]
----
AgeInYears() >= 18 and AgeInYears() < 65
----

Komet concept: *And*

[[term-as]]
[discrete]
==== *as*

`Type Operator` -- (Core Operators > Type Operator) Not yet in Komet

Casts a value to a specified type at compile time (null at run time if the value isn’t that type); also declares a parameter’s or argument’s type.

[source,cql]
----
define function "GetQuantity"(obs Observation): obs.value as Quantity
----

[[term-case]]
[discrete]
==== *case*

`Conditional Expression` -- (Query & Control Flow > Conditional Expression) Not yet in Komet

Begins a case expression, which evaluates when/then branches (or compares a value against candidates) and returns the first match.

[source,cql]
----

  when "Age" < 65 then 'Adult'
  else 'Senior'
end
----
