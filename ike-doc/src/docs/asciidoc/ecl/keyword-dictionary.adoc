[#ecl-keyword-dictionary]
== Keyword Dictionary

All 48 ECL keywords, alphabetically. Category, definition, and example for each.

[[ecl-term-accept]]
[discrete]
==== *accept*

`Description Filter` -- (Filters > Description Filter)

Acceptability token: the description is acceptable in the dialect.

[source,ecl]
----
< 64572001 |Disease| {{ dialect = en-gb (accept) }}
----



* * *

[[ecl-term-active]]
[discrete]
==== *active*

`Component Filter` -- (Filters > Component Filter)

Filters descriptions, concepts or members by active status (true/1, false/0, or *).

[source,ecl]
----
< 195967001 |Asthma| {{ C active = true }}
----



* * *

[[ecl-term-ancestorOf]]
[discrete]
==== *ancestorOf*

`Hierarchy Operator` -- (Constraint Operators > Hierarchy Operator)

Selects all ancestors of the focus concept, excluding the concept itself (brief syntax >).

[source,ecl]
----

----
