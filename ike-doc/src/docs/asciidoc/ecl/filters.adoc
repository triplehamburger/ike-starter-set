== Filters

=== Description Filter (14)

Filters on a concept's descriptions (term, language, type, dialect, identifier), with the term search types and the description type and acceptability tokens they compare against.

Members: <<ecl-term-accept,`accept`>>, <<ecl-term-def,`def`>>, <<ecl-term-dialect,`dialect`>>, <<ecl-term-dialectId,`dialectId`>>, <<ecl-term-fsn,`fsn`>>, <<ecl-term-id,`id`>>, <<ecl-term-language,`language`>>, <<ecl-term-match,`match`>>, <<ecl-term-prefer,`prefer`>>, <<ecl-term-syn,`syn`>>, <<ecl-term-term,`term`>>, <<ecl-term-type,`type`>>, <<ecl-term-typeId,`typeId`>>, <<ecl-term-wild,`wild`>>

=== Concept Filter (4)

Filters on a concept's own definition status, with the definition status tokens.

Members: <<ecl-term-defined,`defined`>>, <<ecl-term-definitionStatus,`definitionStatus`>>, <<ecl-term-definitionStatusId,`definitionStatusId`>>, <<ecl-term-primitive,`primitive`>>

=== Component Filter (8)

Keywords shared by description, concept and member filters: the filter type letters (D, C, M), module, effective time, and active with its boolean values.

Members: <<ecl-term-active,`active`>>, <<ecl-term-C,`C`>>, <<ecl-term-D,`D`>>, <<ecl-term-effectiveTime,`effectiveTime`>>, <<ecl-term-false,`false`>>, <<ecl-term-M,`M`>>, <<ecl-term-moduleId,`moduleId`>>, <<ecl-term-true,`true`>>
