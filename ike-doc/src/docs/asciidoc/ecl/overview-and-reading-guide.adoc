== Overview and Reading Guide

ECL (the SNOMED CT Expression Constraint Language) is the SNOMED International language for defining a bounded set of SNOMED CT concepts -- by their place in the hierarchy, their attribute refinements, their reference set membership, and filters on their descriptions, definition status and members. This chapter inventories every keyword in ECL 2.3, the words its brief and long syntax ABNF recognize. Each keyword is also composed into the IKE starter set as a concept, filed under its section in the ECL keyword hierarchy, so Komet, the IKE-Foundation terminology authoring platform, finds it like any other concept.

Keywords are grouped by the 10 sections of the specification's ECL Core Brief Syntax chapter that introduce them -- Simple Expression Constraints, Refinements, Cardinality, Conjunction and Disjunction, Exclusion and Not Equals, Description Filters, Concept Filters, Member Filters, History Supplements, and Top and Bottom -- each a top-level section below. The keywords shared by description, concept and member filters (moduleId, effectiveTime, active, true, false) belong to all three filter sections.

Every textual ECL keyword is case insensitive. Many have a symbol in the brief syntax (`<` for descendantOf, `^` for memberOf); each entry's definition names it.

Each entry in the <<ecl-keyword-dictionary,Keyword Dictionary>> states, in order:

* Its *section* (e.g. `Simple Expression Constraints`) within the ECL Core Brief Syntax chapter
* A plain-language *definition*
* A worked *example* -- illustrative ECL, written to show the keyword in a realistic SNOMED CT context
